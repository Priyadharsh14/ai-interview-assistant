# AI Interview Preparation Assistant

An AI-powered application that helps job seekers prepare for interviews by analysing their resume against a specific job description.

**Live Demo**: [Add your link here]

## Setup

1. Add your `GROQ_API_KEY` in Streamlit Cloud secrets
2. Deploy directly from this repo

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app/main.py
```
